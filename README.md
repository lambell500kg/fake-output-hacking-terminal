# Fake Output Hacking Terminal

A Python GUI application built with `Tkinter` that simulates a classic green-on-black hacker terminal. Mash any keys on your keyboard to rapidly generate hacking code, and reveal custom text or image outputs on demand.

## Features

* **Realistic Code Typing Simulation:** Press any key (except F11 and Enter) to type out fake hacking code at high speed (It's just linux kernel code).
* **Customizable Output Modes:** Choose between `text`, `image`, or `both` before launching the terminal session, and press Enter to reveal your custom output.
* **Fullscreen Support:** Press `F11` at any time to toggle fullscreen mode for a realistic movie-style terminal experience.
* **Standalone Windows App:** Available as a single `.exe` file—no Python installation required.

## Download & Run

### Option 1: Windows Executable (Recommended)
1. Go to the [Releases](https://github.com/lambell500kg/fake-output-hacking-terminal/releases) page.
2. Download `app.exe` from the latest release (`v1.0.0`).
3. Double-click `app.exe` to run (if Windows SmartScreen appears, click **More info** > **Run anyway**).

### Option 2: Run from Source (Python)
1. Clone or download this repository:
   ```bash
   git clone https://github.com/lambell500kg/fake-output-hacking-terminal.git
   cd fake-output-hacking-terminal
   ```
2. Run the script (requires Python 3.x with `tkinter`):
   ```bash
   python app.py
   ```
